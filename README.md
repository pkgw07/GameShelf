# SteamShelf (게임 장부) v1.0.0

Steam 라이브러리를 불러와서 게임 수, 가격(정가·현재가·역대 최저가·실제 지출), 플레이타임, 도전과제, 장르 취향 추천, 엔딩까지 남은 시간을 보여 주는 Windows 데스크톱 프로그램입니다.

## 설치하기

1. [Releases 페이지](https://github.com/pkgw07/SteamShelf/releases/latest)에서 `SteamShelf-Setup-버전.exe`를 받아 실행합니다.
2. Windows가 "PC 보호" 창을 띄우면 **추가 정보 → 실행**을 누릅니다. 코드 서명 인증서가 없는 개인 프로그램이라 처음 한 번 뜨는 경고입니다.
3. 프로그램이 열리면 **설정**에서
   - Steam Web API 키 입력 ([발급 페이지](https://steamcommunity.com/dev/apikey), 도메인 칸에는 `localhost` 같은 아무 이름)
   - 계정 칸에 프로필 주소나 SteamID64를 넣고 **연결**
   - (선택) IsThereAnyDeal API 키 입력 ([발급 페이지](https://isthereanydeal.com/apps/my/)) → Steam 역대 최저가와 과거 할인 이력
4. 연결하면 첫 동기화가 자동으로 시작됩니다. 게임 수에 따라 몇 분 걸립니다.

> Steam 프로필의 **게임 세부 정보**와 **위시리스트**가 공개여야 불러올 수 있습니다.

## 업데이트

설치한 프로그램이 켜질 때와 6시간마다 새 버전을 확인합니다. 새 버전이 있으면 화면 위에 알림이 뜨고, **업데이트 받기 → 다시 시작해서 설치**를 누르면 됩니다. 데이터는 그대로 유지됩니다.

## 새 버전 배포하기 (개발용)

1. `package.json`의 `version`을 올리고 `CHANGELOG.md`에 변경 내용을 적습니다.
2. 커밋 메시지에 `[release]`를 넣어 `main`에 올리면 GitHub Actions가 설치 파일을 만들어 `v버전` 이름으로 Releases에 게시합니다. (`v버전` 태그를 올리거나 Actions 화면에서 직접 실행해도 됩니다.)
3. `main`에 올리기만 하면 빌드 검사만 하고, 설치 파일은 Actions 실행 결과물에 남습니다.

로컬에서 개발할 때는 Node.js 22 이상에서 `npm install` 후 `npm run dev`.

## 1.0 기능

| 화면 | 내용 |
|---|---|
| 대시보드 | 라이브러리 장부(정가/현재가/역대 최저가/실제 지출 총합), 안 한 게임 수, 총 플레이타임, 도전과제 달성률, 엔딩까지 남은 시간, 오래 안 한 "플레이 중" 게임 |
| 라이브러리 | 검색·필터(플레이함/안 한 게임/할인 중/제외됨)·정렬, 카드/표 보기, 여러 게임 선택해서 상태 변경·제외 |
| 게임 상세 | 상태 태그, 통계 제외, 구매가·구매일, 시간당 비용, 구매 타이밍 평가, 한국/미국 가격, 가격 그래프, 평균 엔딩 시간, 메모·평점, 도전과제(달성일·희귀도), 플레이 세션 |
| 가격·지출 | 가격 총합 4종(원화 + 게임별 미국 정가 기준 달러), 연/월별 지출, 가성비 순위, 구매 타이밍, 한국 vs 미국 정가 비교, 구매 내역 가져오기, 구매가 빠른 입력 |
| 할인·위시리스트 | 위시리스트 할인 현황과 "역대 최저가 / 최저가 근접 / 더 기다리기" 판정, 보유 게임 할인 |
| 게임 가격 검색 | 보유하지 않은 게임도 검색해서 지금 할인이 역대 최대인지 확인 |
| 추천 | 플레이타임 가중 장르 취향, 안 한 게임 중 먼저 할 만한 것, 새로 살 만한 게임 |
| 활동 기록 | 하루 플레이타임 그래프, 기간별 많이 한 게임, 월별 도전과제, 플레이 세션 |
| 설정 | 안 한 게임 기준(분), 제외 규칙, 상태 태그 자동 제안, 테마(시스템/라이트/다크), 트레이·자동 실행·플레이 감지, 백업/복원/CSV |

### 자동으로 하는 일
- **하루 한 번 자동 기록**: 가격(한국·미국)이 바뀐 날과 플레이타임을 기록합니다. 트레이에 있거나 창이 열려 있을 때만 동작하므로 "컴퓨터를 켤 때 자동 실행"을 켜 두는 것을 권장합니다.
- **플레이 중 감지**: Windows 레지스트리의 Steam `RunningAppID` 값을 30초마다 읽습니다(네트워크 사용 없음). 게임을 끄면 2분 뒤 플레이타임과 도전과제를 갱신합니다.
- **상태 태그 자동 제안**: 도전과제 100% → "100%", 최근 2주 플레이 → "플레이 중". 직접 고른 태그는 절대 바꾸지 않습니다.

### 구매가 넣는 방법
Steam API로는 구매 가격을 알 수 없어서 두 가지 방법을 지원합니다.
1. **구매 내역 가져오기**: 브라우저에서 [Steam 구매 내역](https://store.steampowered.com/account/history/)을 끝까지 펼친 뒤 `Ctrl+S`로 저장 → 가격·지출 화면에서 열기. 한 결제에 여러 게임이 있으면 정가 비율로 나눕니다. [라이선스 페이지](https://store.steampowered.com/account/licenses/)도 같은 방법으로 가져오면 획득일이 채워집니다.
2. **직접 입력**: 게임 상세 또는 가격·지출 화면의 "구매가 빠르게 입력".

직접 입력한 값은 가져오기가 덮어쓰지 않습니다.

## 데이터와 개인정보
- 모든 데이터는 이 컴퓨터의 `%APPDATA%\SteamShelf\steamshelf.db` 에만 저장됩니다.
- API 키는 Windows 보안 저장소(DPAPI)로 암호화해서 저장합니다.
- Steam 로그인 정보는 입력받지 않습니다.

## 데이터 출처
- Steam Web API / Steam 상점: 게임 목록, 플레이타임, 도전과제, 가격, 위시리스트
- [IsThereAnyDeal](https://isthereanydeal.com/): Steam 역대 최저가, 과거 할인 이력
- HowLongToBeat: 평균 엔딩 시간 (공식 API가 없어 사이트 검색을 이용, 실패하면 직접 입력)
- SteamSpy: 추천 후보 목록

## 폴더 구조

```
src/
  shared/         화면과 메인 프로세스가 같이 쓰는 타입·계산(analytics.ts)
  main/           Electron 메인 프로세스
    db/           SQLite 스키마와 저장소(repo.ts)
    providers/    플랫폼 어댑터 (steam.ts). PSN/Xbox/Switch는 여기에 추가
    services/     동기화, 가격 기록, ITAD, HLTB, 추천, 가져오기, 플레이 감지
  preload/        화면에 window.api 노출
  renderer/       React 화면
resources/        아이콘
```

### 다른 플랫폼 추가하기
`src/main/providers/types.ts` 의 `PlatformProvider` 를 구현하고 `providers/index.ts` 에 등록하면 됩니다. DB는 `games(platform, game_id)` 구조라 Steam 외 플랫폼 게임도 같은 테이블에 들어갑니다.

## 문제 해결
- **게임 목록이 비어 있음**: Steam 프로필의 게임 세부 정보를 공개로 바꾼 뒤 다시 동기화하세요.
- **동기화 경고**: 설정 → 데이터 → "지난 동기화 경고"에서 어떤 요청이 실패했는지 볼 수 있습니다.
